Project name: Simple math equations.

The project allows the user to perform simple mathematical calculations and record the equations on the text file.

-It requests for the first and second values involved in the calculation (input).  
-Allows the user to select their preferred operator. 
-The equation and the answer are written in the text file (output). 
- The code uses the try and except method to avoid crashing. 
- It also accounts for common errors such as dividing by zero. 

The the project allows you to make simple math calculations are using the common operators found on the keyboard
